{% trans "FAQ" %}

{% trans "Who can use LUT Kyyti?" %}

{% trans "LUT Kyyti is intended for LUT and LAB employees. Access is limited to verified LUT/LAB users." %}

{% trans "How does LUT Kyyti work?" %}

{% trans "Drivers post rides they are already planning to make. Passengers can search for suitable rides and request to join. They can also post ride requests. The driver and passenger then agree on the practical details." %}

{% trans "Is LUT Kyyti a taxi or transport service?" %}

{% trans "No. LUT Kyyti is not a taxi, bus, or transport provider. It is a platform that helps members of the LUT/LAB community find others travelling in the same direction." %}

{% trans "Is using LUT Kyyti free?" %}

{% trans "Using the platform is free. Any cost sharing between driver and passenger, such as fuel costs, is agreed directly between the users. LUT Kyyti does not handle payments." %}

{% trans "Can I offer a recurring ride?" %}

{% trans "Yes. If you regularly commute on the same route, you can post a recurring ride so others can join when suitable." %}

{% trans "Can I look for travel companions for train, bus, or taxi trips?" %}

{% trans "Yes. You can also post a trip if you are looking for others to share public transport or taxi travel." %}

{% trans "Is LUT Kyyti safe to use?" %}

{% trans "LUT Kyyti is intended for verified LUT/LAB community members, which makes it different from an open public marketplace. Users should still use normal care when agreeing to share a ride." %}

{% trans "Can students use LUT Kyyti?" %}

{% trans "During the pilot phase, LUT Kyyti is only available to LUT and LAB employees. The service may be opened to LUT and LAB students after successful deployment of the pilot." %}
