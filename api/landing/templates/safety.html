{% trans "Safety and Ride Etiquette" %}

{% trans "LUT Kyyti helps members of the LUT and LAB community find others travelling in the same direction. To keep the service useful, respectful, and safe for everyone, users are expected to communicate clearly, behave responsibly, and use normal care when arranging shared rides." %}


{% trans "LUT Kyyti is not a taxi, bus, or transport service. It is a platform for connecting verified users. Drivers and passengers are responsible for agreeing on the practical details of each ride between themselves." %}


{% trans "Before sharing a ride" %}


{% trans "Before joining or offering a ride, make sure the key details are clear. These may include:" %}

  • {% trans "departure point and destination" %}
  • {% trans "pickup and drop-off location" %}
  • {% trans "date and time" %}
  • {% trans "whether the time is flexible" %}
  • {% trans "return-trip details, if relevant" %}
  • {% trans "possible cost sharing" %}
  • {% trans "luggage or special arrangements" %}
  • {% trans "how to contact each other if plans change" %}

{% trans "Do not assume that all details are understood automatically. A short confirmation message before the ride can help avoid confusion." %}


{% trans "Communication" %}


{% trans "Be polite, clear, and timely when communicating with other users." %}


{% trans "If you are offering a ride, describe the trip accurately. If you are requesting a ride, explain what you need clearly. If plans change, inform the other person as early as possible." %}


{% trans "Users should not pressure others to accept a ride, change their route, share personal information, or continue with an arrangement they are not comfortable with." %}


{% trans "Cost sharing" %}


{% trans "LUT Kyyti does not handle payments. Any possible cost sharing is agreed directly between the driver and passenger." %}


{% trans "If cost sharing is expected, agree on it before the ride. The amount should be reasonable and related to sharing travel costs, such as fuel or parking. LUT Kyyti should not be used as a commercial taxi or transport service." %}


{% trans "During the ride" %}


{% trans "Drivers and passengers should behave respectfully during the trip." %}

{% trans "Please be on time, keep the vehicle clean, and respect the other person’s preferences. For example, agree before the ride if there are questions about music, food, pets, smoking, luggage, or other arrangements." %}


{% trans "Drivers are responsible for driving safely and following traffic laws. Passengers should not distract the driver or ask the driver to take unsafe actions." %}


{% trans "If you are late or need to cancel" %}


{% trans "Plans can change. If you are late or need to cancel, tell the other person as soon as possible." %}


{% trans "Repeated late cancellations, no-shows, or unclear communication make the service less reliable for everyone. Please respect the other person’s time and travel needs." %}


{% trans "Personal safety" %}


{% trans "LUT Kyyti is intended for verified LUT/LAB users, which makes it different from an open public marketplace. Users should still use normal care when arranging shared rides." %}


{% trans "If something feels wrong, you are not required to join or continue with a ride. You can decline a ride, change your plans, or leave the situation if you feel uncomfortable." %}


{% trans "When meeting another user for the first time, you may choose a clear and familiar pickup location, such as a campus area, public transport station, or other public place." %}


{% trans "Privacy and personal information" %}


{% trans "Only share personal information that is necessary for arranging the ride. Do not share another user’s contact details, travel plans, or personal information with others without permission." %}


{% trans "Use the contact information available through LUT Kyyti only for arranging rides or related communication." %}


{% trans "Reporting concerns" %}


{% trans "If you experience inappropriate behaviour, repeated no-shows, misuse of the service, or anything that makes you feel unsafe, please contact the LUT Kyyti team." %}


{% trans "In urgent situations or emergencies, contact the appropriate emergency services directly." %}


{% trans "Shared responsibility" %}


{% trans "LUT Kyyti works best when users treat each other with respect and communicate clearly. By using the service, you help create a more practical, social, and climate-friendly commuting culture within the LUT and LAB community." %}
